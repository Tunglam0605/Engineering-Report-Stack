# Review Engineering Report

Review the report using Engineering Report Stack rules.

Check in this order:

1. Canonical data ownership.
2. JSON Schema validity.
3. Stable ID uniqueness.
4. Referential integrity.
5. Traceability completeness.
6. Source/citation correctness.
7. Evidence existence and provenance.
8. Generated output freshness.
9. Build status.
10. Search/filter behavior.
11. Diagram consistency.
12. Duplicate sections/cards/facts.
13. Responsive/readability regression.

Classify findings as Blocker, Major, or Minor. Do not approve only because the page looks visually correct.
